# Tablero de control APN

Accesos, cobranzas y deuda de la Administración de Parques Nacionales. Corte al 31/10/2026; ciclos nov 23–oct 24, nov 24–oct 25 y nov 25–oct 26.

- `index.html` — tablero (PWA instalable, funciona sin conexión).
- `informe/` — informe PDF de 24 láminas, enlazado desde el botón «Informe PDF» y la barra de secciones.
- `descargas/tablero-de-control-apn.html` — versión de un solo archivo, con el PDF incrustado.
- `tools/` — scripts de actualización (ver `tools/README.md`).

Publicación: GitHub Pages mediante `.github/workflows/pages.yml`. El repositorio incluye nombres de deudores.
